# Visual Mod

Enhanced Visuals Engine and Ambience Controller for Roblox.

## ✨ Features
- **Ambience Controller**: Real-time atmospheric lighting, celestial skybox, depth fog, dynamic bloom, and color correction.
- **Character Mod Engine**: Synchronized RGB neon effects, premium Ghost mode with soul wisps, customizable particle auras.
- **Jump Particle Ring**: Dynamic expanding celestial rings with smooth trails when jumping.
- **PvP Combat Hit Effects**: Geometric convergence impact crests (Astral Star, Arcane Hexagram, Radiant Diamond, Cosmic Nova) triggered only on actual damage from melee attacks, ranged weapons, and skill keys (1, 2, 3, 4).

## 🚀 Script Loader
Execute the following script in your executor:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/SellAllMan/visual-mod/main/ambience_controller.lua"))()
```

Or run locally if placed in your workspace folder:
```lua
loadfile("ambience_controller.lua")()
```
